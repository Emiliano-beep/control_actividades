1. Explica la diferencia entre Git y GitHub.

R = Git es un controlador de versiones y github es una plataforma para poder subir tus git y poder colaborar e interactuar con otras personas.

2. Explica para qué sirve .gitignore.

R= Le indica al git que archivos no debe tomar en cuenta, para que estos no se muestren en github. 

3. Explica por qué .venv no debe almacenarse normalmente en GitHub.

R = Por que .venv tiene muchos archivos, incluyendo las dependencias del proyecto, cada computadora puede instalar las dependencias del proyecto para reconstruirlo y que pueda servir. 

4. Explica para qué sirve requirements.txt.

R = Guarda las dependencias del proyecto

5. Explica la diferencia entre Stage, Commit y Push.

R = Stage es para preparar para hacer un commit es como mandarlo a la zona de preparacion, el commit es para poner un punto en el historial, y el push es para subirlo a github.

6. Explica por qué un repositorio puede tener varios commits antes de realizar un push.

R= Por que los commits sirven para que los demas colaboradores sepan y vean que hiciste en tu parte, los commits solo son puntos en el historial del repositorio.
